How Sentinel decides

A RandomForestClassifier trained on 40 lexical, structural, and brand-similarity features extracted directly from the URL string — no live network calls needed, so scoring is instant.

Feature families

  • length & structure — URL/host/path length, dot & hyphen counts, special characters
  • obfuscation — IP-literal hosts, punycode, homoglyphs, percent-encoding, shorteners
  • brand similarity — typosquat edit-distance to 20+ commonly-spoofed brands
  • semantic — login/verification keyword density, redirect parameters, malware-style file extensions
  • statistical — domain entropy, digit/letter ratio, case-switch anomalies

What the model weighs most

Educational project. Trained on a synthetic, rule-generated dataset — swap in real labeled data (PhishTank / OpenPhish) for production use. Not a substitute for enterprise email/web security filtering.
